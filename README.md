# StrikeOnline

Android-first 3D FPS prototype built with Godot 4.4.

## Current prototype
- First-person camera and mouse look
- WASD movement, jump and gravity
- Procedurally-built industrial training arena
- Placeholder first-person rifle
- Hitscan shooting, 30-round magazine and reload
- Damageable practice targets

## Controls
- WASD: move
- Mouse: look
- Left mouse button: fire
- R: reload
- Space: jump
- Esc: release mouse

This is an original game prototype inspired by the competitive mobile FPS genre. It does not contain Standoff 2 assets or branding.

## Build
Open project.godot in Godot 4.4 or newer. Android debug APK export is configured through GitHub Actions in .github/workflows/android-apk.yml.
